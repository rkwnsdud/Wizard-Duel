# Previous Basic Wand attack sound

`Assets/Audio/BasicWand/BasicWandCast.wav` is the previous, procedurally
synthesized Arcane Bolt launch sound. It is kept for reference but is no longer
assigned to the Basic Wand prefab. Its 0.34-second length stays below the Basic
Wand's 0.65-second base attack cooldown. The sound uses 48 kHz mono, 16-bit PCM
and is generated by `Docs/BasicWand/GenerateCastSound.ps1`.

The prefab now uses `Assets/Audio/BasicWand/ArcaneBolt_Fire.wav`; its source,
license, and edit details are recorded in `Docs/BasicWand/ArcaneBolt_Fire_License.md`.

The sound and generator are licensed under 0BSD. The prior
`magic-projectile-04.wav` is a separate asset and is not covered by this license.
