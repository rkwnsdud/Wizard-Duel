# 완드 공격: 번개 원본 모션 적용

실제 번개 무기 `Cast` 상태가 참조하는 `Assets/Weapons/Common/BaseCast.anim`(0.65초)을 복사해 완드 공격 클립 2개에 적용했다. 공통 클립과 `WizardLocomotion.controller`, 번개 무기를 사용하는 `Player.prefab`은 유지한다. 이전에 따로 만든 오른발 디딤과 전신 키포즈는 제거했다.

복사본은 번개 원본의 준비·발사·복귀 속도, 골반·척추·다리 움직임을 사용한다. 완드 대기 자세에서 손이 튀지 않도록 오른쪽 아래팔·손·손가락 17개 관절을 파지 기준으로 옮겼고, 발사 전후에만 오른팔·아래팔·손을 조준 자세로 부드럽게 연결했다. Player와 Dummy의 완드 장착 각도 차이는 각각의 클립에서 보정한다. 공격이 끝나면 완드 대기 자세로 돌아온다.

- `BasicWandAttack.anim`: Player용 복사본.
- `BasicWandAttack_DummyGrip.anim`: Dummy용 복사본.
- 발사 이벤트 `FireMagic`: 0.20초, 1회.
- 종료 이벤트 `EndAttack`: 0.65초, 1회.
- 번개 전용 이벤트는 복사하지 않았다. 기존 완드의 `BasicWandIdlePose`와 `PlayerAttack`은 완드 공격에서 이전 번개 무기 발사를 막는다.

`lightning-offline-validation.txt`는 원본 몸통·다리 곡선 13개가 일치하고, 발사 시 완드 방향 오차가 0°이며 오른손목 각도가 Player 5.39° / Dummy 15.35°임을 기록한다. 오른팔 키 간 최대 회전량은 18.95° / 19.01°이다. 발 궤적은 원본과 동일하다. 손가락 시작·종료 자세와 이벤트도 검사했다.

Unity 메뉴 `Tools > Basic Wand > Build Attack`은 같은 번개 원본을 이용해 클립을 다시 작성하는 편집기 생성기다. `Tools/aim_wand_offline.py`도 같은 팔 목표와 보간을 사용한다. 클립을 다시 작성한 경우 Blender 4.2의 `Tools/check_wand_aim_offline.py`로 확인한다.

2026-11-03 손 자세 수정: 새 녹화에서 손이 몸 오른쪽으로 벌어져 보이는 현상을 확인했다. 발사 시 손 목표의 좌우 위치를 팔 길이 기준 0.30에서 0.09로 줄여 몸 전방에 두고, 완드 축을 따라 손바닥이 100° 이상 돌아가던 회전을 최대 78°로 제한했다. 손가락 파지와 완드 소켓 변환은 유지한다. 재검사 결과 두 캐릭터의 공격 전체 손목 각도는 50° 미만이고, 오른팔 인접 키 회전량은 번개 원본보다 작다.

2026-11-03 빈 왼손 수정: 번개 원본의 왼쪽 아래팔은 대기 자세에서 최대 79.37° 회전해, 빈 손이 로브 옆에서 꺾여 보였다. 완드 복사본에서는 왼쪽 아래팔 회전을 40%로 줄여 최대 31.75°로 제한하고, 왼손 로컬 회전을 완드 대기 자세로 유지한다. 키 사이 최대 회전량은 13.64°에서 5.46°로 줄었다. 왼쪽 윗팔과 몸통·다리·오른손 파지는 유지한다. 변경 후 Unity 플레이 화면은 아직 확인하지 못해 로브 관통과 대기 전환의 시각적 상태는 미검증이다.

2026-11-12 `DuelOfflineTest` 발사 자세 수정: 그 씬의 `DuelWizard` 프리팹은 `PlayerTest`에만 있던 완드 전용 대기 자세와 손 메시 설정을 받지 못하고 있었다. `BasicWandWeapon`이 장착된 플레이어에 해당 설정을 연결한다. 공격 클립의 손목 보정에서 손과 완드를 따로 돌리던 `WeaponSocket` 키를 제거하고, 팔꿈치·손을 함께 조준하도록 다시 만들었다. 발사 시 손목은 Player 5.39° / Dummy 15.35°, 공격 중 최대 26.86° / 28.63°이고 완드 방향 오차는 0°이다. `FireMagic`과 `EndAttack` 이벤트는 유지한다. 기본 완드 효과음은 사용자가 요청한 `ArcaneBolt_Fire.wav`, 피치 1.1이다. Unity 플레이 화면은 아직 확인하지 못했다.
