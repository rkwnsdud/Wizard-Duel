# 완드 공격 자세 및 파지 검증 (2026-11-12)

## 원본 팔꿈치 굽힘축 복원 (현재 적용)

이전 자세의 아래팔 회전은 원본 Cast의 팔꿈치 굽힘축과 반대 방향이었고 축 회전도 섞여 있었다. `BaseCast.anim` .10초의 RightForeArm 회전에서 실제 굽힘축을 구하고, 공격 아래팔 곡선을 **그 축의 정방향 18° 굽힘**으로 교체했다. 어깨/아래팔 회전을 절반씩 나누던 보정은 제거했다. 키 사이 보간도 단조 탄젠트로 바꿔 복귀 중 미세하게 반대로 꺾이는 현상을 없앴다.

팔꿈치는 어깨 기준 바깥·아래, 손등은 오른쪽·위를 향하며 팔 도달 거리는 전체 길이의 98.77%이다. 1301회 보간 검사에서 팔꿈치 축 비틀림과 역방향 굽힘이 없는지 직접 검사한다. 손목 굽힘은 최대 24°이다.

원래 파지와 자연스러운 굽힘 방향을 유지하기 위해 완드의 시각적 방향은 수평에서 Player 32° / Dummy 36° 위로 기울였다. 발사 이벤트, 발사 코드의 실제 방향, FirePoint 로컬 위치/회전, 완드 장착 및 Idle 파지는 변경하지 않았다. 이는 완드 시각 방향을 수평에 강제하던 이전 조건과 다르다. 최신 수치는 상위 `neutral-wrist-validation.txt`에 있으며 실제 Unity 시각 확인은 사용자에게 맡긴다. 기존 PNG와 Unity 보고서는 이전 자세의 기록이다.

## 이전 팔꿈치·손등·팔 뻗기 동시 제약 기록

팔꿈치의 바깥·아래 위치는 **몸통/어깨 기준**으로 적용한다. 팔꿈치를 손보다 바깥에 강제로 접던 이전 방식은 제거했다. 팔꿈치는 어깨보다 바깥쪽 약 5.2cm, 아래쪽 약 3.0cm에 두고 손등은 캐릭터의 오른쪽 위를 향하도록 완드 조준과 함께 계산한다. 팔을 뻗되 잠그지 않아 발사 시 팔꿈치 굽힘은 Player 26.35° / Dummy 36.42°, 어깨–손 도달 거리는 전체 팔 길이의 97.38% / 95.01%이다.

손목은 18°의 작은 굽힘만 주며 별도의 축 비틀기를 추가하지 않는다. 조준 유지 구간 전체에서 손등의 오른쪽·위 성분과 팔꿈치의 바깥·아래 위치를 동시에 검사한다. 손목의 전체 로컬 회전 차이도 20° 미만으로 제한해 단순 굽힘 각도에 숨은 비틀기를 방지한다. 발사 시 윗팔의 Idle 대비 회전 차이는 약 76°, 아래팔은 약 27° / 37°이며 한 관절에 큰 회전을 몰아주지 않는다.

1301회 보간 검사 통과. 손가락·장착·Idle·발사 이벤트와 타이밍은 유지한다. 최신 수치는 상위 `neutral-wrist-validation.txt`에 기록했다. Unity 시각 확인은 사용자에게 맡기며 아래의 이전 자세 수치와 PNG는 현재 결과를 나타내지 않는다.

## 이전 팔꿈치 바깥쪽·아래쪽 배치 기록

손등 방향을 강제하던 회전 기준을 제거했다. 윗팔은 바깥쪽·살짝 아래로 향하고, 전완은 팔꿈치에서 앞쪽 손으로 돌아오도록 배치한다. 발사 순간 팔꿈치는 손보다 바깥쪽 약 18.1cm, 아래쪽 약 4.8cm에 있다(클립 좌표 기준). 손목은 별도 축 비틀기 없이 조준의 잔여 각도만 부드럽게 굽힌다. 최대 굽힘은 Player 9.55° / Dummy 19.52°이며 준비·복귀 때 Idle로 보간한다. 손가락·완드는 손과 함께 움직이므로 기존 파지를 유지한다.

오프라인 보간 검사 1301회 통과. 발사 조준 오차 약 0°, Idle 양끝 자세·손가락 곡선·장착 위치·이벤트·타이밍은 보존했다. Unity 시각 확인은 사용자에게 맡긴다. 아래의 손등 위 강제 자세와 이전 PNG는 현재 결과가 아니다.

## 이전 실물 사진 해석 기록

손등이 위를 향하고 팔을 전방으로 더 뻗는 실물 사진에 맞춰 팔 전체 회전을 수정했다. 이전의 아래팔 방향을 기준으로 한 회전 대신, 검지·소지 뿌리가 만드는 실제 손바닥 평면에서 손등 방향을 구해 회전한다. 손목에는 별도 회전을 더하지 않는다. 발사 시 팔꿈치 굽힘은 Player 46.67° / Dummy 55.64°로 완화했고 손등과 위쪽 방향 내적은 각각 .938 / .927이다. 이전 자세의 81° / 91° 굽힘은 현재 사용하지 않는다.

Idle, 손가락 15개 본, 소켓·완드 장착, FirePoint, 발사 이벤트와 타이밍은 그대로 유지했다. 오프라인 보간 검사를 통과했고 최신 수치는 상위 `neutral-wrist-validation.txt`에 있다. 사용자 요청에 따라 이번 수정의 Unity 시각 확인과 Play Mode 확인은 사용자가 수행한다. 아래 검증 결과와 PNG, `unity-validation.txt`는 이전 자세의 기록이므로 이번 사진 기준 수정 결과로 해석하지 않는다.

## 이전 자세의 수정 및 검증 기록

수정 대상은 `BasicWandAttack.anim`, `BasicWandAttack_DummyGrip.anim`의 `RightArm`(UpperArm), `RightForeArm`(LowerArm), `RightHand` 회전과 대응 편집기 곡선이다. 몸통·다리·빈 왼손, 위치 곡선, 이벤트 데이터와 시간, 클립 설정은 보존했다.

실제 계층은 `Wizard/WizardModel/Armature/Hips/Spine02/Spine01/Spine/RightShoulder/RightArm/RightForeArm/RightHand`이다. 손 아래에 Thumb/Index/Middle/Ring/Little 각각 3마디와 `WeaponSocket/BasicWand/FirePoint`가 있다. 소켓은 손 기준 위치 0, 회전 identity, 스케일 1이다. 기존 공격의 손가락 15개 본은 이미 정상 Idle 파지를 사용하므로 수정하지 않았다.

완드 조준 후 손목을 최대 78° 추가 회전하던 처리를 제거했다. 손목은 전체 공격에서 정상 Idle 로컬 회전을 유지한다. 윗팔·아래팔이 손과 완드 전체를 조준하며, 팔꿈치는 손보다 아래·약간 바깥에 둔다. 발사 순간 팔꿈치 굽힘은 Player 약 81°, Dummy 약 91°이다. 현재 장착 상태에서 완드 축과 전완 사이 각도가 각각 약 60°/70°이므로 이 굽힘으로 중립 손목과 기존 파지를 함께 보존한다.

0–.20초 준비, .20–.26초 조준 유지, .26–.55초 복귀를 부드럽게 연결하고 .65초 종료 시 Idle 자세를 유지한다. `FireMagic .20s`, `EndAttack .65s`를 유지했다. Idle 클립, 손 메시/스킨, WeaponSocket, 완드 장착 위치·각도·스케일, FirePoint, 무기 코드, 컨트롤러는 수정하지 않았다.

## 검사 결과

- 오프라인에서 키 사이 Hermite 보간을 포함해 0.5ms 간격으로 1301회 검사했다. 손목 굽힘 약 0°, 발사 조준 오차 약 0°, 손가락 Idle 차이 약 0°이다. 오른팔 인접 키 최대 회전은 Player 17.22°, Dummy 17.18°이다.
- Unity에서 실제 클립을 5ms 간격으로 131회 샘플링했다. 손목 굽힘 최대 0.028°, 발사 조준 오차 0°이다.
- 캐릭터별 손·손가락 정점 474개를 실제 본 행렬과 bind pose로 스키닝했다. 손 기준 표면 위치는 정상 Idle과 최대 약 0.000002m 차이로 일치했다. 손가락과 소켓의 상대 행렬도 계산 오차 이내로 유지된다. 따라서 공격이 정상 Idle에 없던 미끄러짐·관통·파지 이탈을 추가하지 않는다.
- 양쪽 캐릭터의 준비·발사·복귀 10개 시점 렌더와 발사 시 손 확대 3방향 이미지를 확인했다. 이 검증은 기존 정상 Idle 접촉을 보존하는 검사이며, 새로운 충돌 메시 기반 파지 피팅은 하지 않는다.
- 편집기 스크립트 빌드 통과(오류 0개). 기존 참조 버전 및 미할당 필드 경고가 있다. 실제 Play Mode 발사 테스트는 수행하지 않았다.

`*-sequence.png`: 위 행은 0 / .08 / .16 / .20 / .26초, 아래 행은 .35 / .45 / .55 / .60 / .65초이다. `*-grip-*.png`는 .20초 손 확대이다. 상세 수치는 `unity-validation.txt` 및 상위 `neutral-wrist-validation.txt`를 참조한다.

## 재현
