# 아래팔 비틀림 복원

Player와 Dummy Player의 Basic Wand Idle에 적용했다. 팔을 옆으로 내린 자세는 유지하며, 완드 방향을 기준으로 아래팔을 비틀던 회전을 제거했다.

원본 WizardCombatIdle의 아래팔 프레임에 팔을 아래로 내리는 최소 회전만 곱했다. 별도의 축 회전은 더하지 않는다. 손목은 원본 Idle에 남아 있던 X/Z 굽힘까지 제거하고 길이 축의 회전만 유지했다. 위팔·아래팔·손목 길이 방향을 한 줄로 정렬했다. 손등은 몸 바깥을 향하고, 접힌 손가락 끝은 몸 안쪽을 향한다. 손가락 메시를 숨기거나 잘라낸 것은 아니다.

## 변경 범위

- `WizardCombatIdle_BasicWandGrip.anim`: RightForeArm, RightHand 회전 곡선만 수정.
- `PlayerTest.unity`: 두 캐릭터의 해당 두 본 회전만 적용. 기존 숨김 상태 유지.
- `BasicWandIdleSetup.cs`: 다시 제작할 때도 같은 원본 프레임 보존 방식 사용.
- `BasicWandArmRelaxation.cs` 및 meta: 명시적으로 실행하는 편집 모드 적용·검사 도구.
- 이 폴더의 검사 결과와 앞·바깥·뒤 렌더링 이미지.

손가락 애니메이션과 파지, 완드의 손 기준 위치·회전·스케일, 세 정점의 스킨 가중치 수정, 왼팔·몸통·하체 곡선, 원본 Idle과 이동·공격 및 Event는 유지했다. 완드의 월드 방향은 자연스러운 손 방향을 따라간다.

## 확인 결과

두 캐릭터 모두 팔꿈치 굴곡과 손목 길이 방향의 꺾임은 약 0.00도다. 손등의 바깥 방향 내적은 0.8556이고, 네 손가락 끝 방향의 바깥 내적은 모두 음수여서 몸 안쪽으로 향한다.

[validation.txt](validation.txt)에 다음을 기록했다.

- 원본 아래팔 축 프레임 보존.
- 수정 대상 두 본 이외의 모든 애니메이션 곡선과 손가락 곡선 일치.
- 클립 길이·루프 설정·Animation Event 보존.
- Idle 시작·끝 회전 동일, 접선 0.
- 양쪽 손가락이 안쪽으로 향함.
- 완드 로컬 Transform과 파지 유지.

이미지는 [Player 바깥쪽](Player-0.png), [Player 앞쪽](Player-1.png), [Dummy 바깥쪽](Dummy-Player-0.png), [Dummy 앞쪽](Dummy-Player-1.png)에서 확인할 수 있다. 숨겨진 더미는 임시 복제본에서만 켜서 렌더링했으며 실제 씬의 표시 설정은 바꾸지 않았다.

원본 FBX·리깅 구조·메시·공격 및 이동 로직은 변경하지 않았다. 새 검증 씬 생성과 Play Mode 실행은 하지 않았다. 임시 자동 실행 스크립트는 적용 후 제거했다.
